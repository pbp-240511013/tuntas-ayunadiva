# Tuntas

Aplikasi to-do list sederhana untuk menyelesaikan tugas satu per satu. Dibuat dengan HTML, CSS, dan JavaScript murni (tanpa library) untuk Praktikum 3A: manipulasi DOM dan localStorage.

## Fitur

- Tambah, ubah, hapus, dan tandai tugas tuntas
- Tingkat prioritas (rendah, sedang, tinggi) dengan penanda warna
- Cincin progres yang bergerak sesuai tugas yang sudah tuntas
- Filter: Semua, Berjalan, Tuntas
- Mode terang dan gelap
- Data tersimpan otomatis di localStorage

## Cara menjalankan

Buka `index.html` di browser, atau pakai ekstensi Live Server di VS Code.
